# Deliverart

> Deliverart is food-delivery management software for restaurants and delivery businesses. It centralizes orders from Just Eat, Glovo, Deliveroo, a restaurant's own website and phone; synchronizes menus across channels; and manages riders, deliveries, take-away and live tracking. The public Deliverart API is an RPC-style HTTPS API (GET reads, POST writes) covering orders, menu, customers, points of sale, workshifts, deliveries and reservations.

## APIs

- [Deliverart API reference](https://apidoc.deliverart.it/): 130 operations across Orders, Menu, Deliveries, Customers, Points of sale, Workshifts and Reservations.
- Base URL: https://pubapi.deliverart.it
- Auth: OAuth2 (password grant, token URL https://auth.deliverart.it/oauth) and API key header X-Deliverart-ApiKey.
